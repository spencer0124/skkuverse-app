# packages/sds

> Skku Design System — `SDSProvider`로 테마를 공급하는 컴포넌트 라이브러리 (37+ 컴포넌트).

## 구조

- `components/` — UI 컴포넌트
- `foundation/` — 파운데이션 (테마 등)
- `core/` — 코어 유틸
- 디자인 토큰 자체는 [`@skkuverse/shared/tokens`](../shared/README.md)에 중앙화 — SDS는 소비자
